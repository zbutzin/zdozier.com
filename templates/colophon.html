How this site works

Every page and the CV are rebuilt each week from public data, plus a few hand-edited files for what no API reports.

{{ section_head('Pipeline', none, 'pipeline') }}

A scheduled GitHub Actions job runs every Monday at 14:00 UTC and whenever the site's code or content files change. It queries six public sources, merges what they report with a few hand-edited files, and rebuilds the pages, the charts, the BibTeX file, the feed, and the CV as HTML and PDF.

Each source is fetched on its own. If one is down, the job keeps that source's last good snapshot and the rest of the site still updates. If a run would drop more than 15% of the listed works at once, the previous list is kept and the run is flagged.

Hand-edited files in content/ hold what no API reports: contribution notes on co-authored papers, research themes, appointments, teaching, talks, and grants from foundations.

{{ section_head('No third-party requests', none, 'privacy') }}

Pages load only files served from this domain. There are no web fonts, analytics, trackers, cookies, or embedded media. Text is set in fonts already on your device, the charts are SVG drawn when the site is built, and the one script ({{ js_kb }} KB) adds the publication filters, the chart tooltips, and the live “synced” label. Every page works without it.
